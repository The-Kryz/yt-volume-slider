# YouTube Volume Slider

Extensão para ajustar o volume dos vídeos do YouTube por meio de um controle deslizante simples e acessível.

## Funcionalidades

- Controle rápido e preciso do volume.
- Interface simples e fácil de usar.
- Integração com o player do YouTube.
- Ajuste do volume sem interromper a reprodução.

## Como usar

1. Instale a extensão seguindo as instruções abaixo.
2. Acesse um vídeo no YouTube.
3. Use o controle deslizante para aumentar ou diminuir o volume.

## Instalação

1. Abra a página de extensões do seu navegador.
2. Ative o **modo desenvolvedor**.
3. Clique em **Carregar sem compactação** (ou **Carregar sem empacotar**, dependendo do navegador).
4. Selecione a pasta deste projeto.

### Navegadores compatíveis

- [Google Chrome — Gerenciar extensões](chrome://extensions/)
- [Microsoft Edge — Extensões](edge://extensions/)
- [Mozilla Firefox — Depuração de extensões](about:debugging#/runtime/this-firefox)
- [Brave — Extensões](brave://extensions/)
- [Opera — Extensões](opera://extensions/)

## Desenvolvimento

Clone o repositório e abra os arquivos do projeto em seu editor:

```bash
git clone <url-do-repositorio>
cd yt-volume-slider
```

Depois, carregue a extensão no modo de desenvolvimento do navegador ou execute o projeto usando as instruções disponíveis nos arquivos de configuração.
